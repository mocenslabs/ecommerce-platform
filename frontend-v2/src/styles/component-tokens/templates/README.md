# Component Token Templates

## Overview

This directory contains the official template used to create new Component Token files.

It exists to ensure consistency across the entire Design System.

Every new component token should start from the provided template instead of copying an existing component.

---

# Available Templates

- golden-template.css

---

# Purpose

The Golden Template defines:

- File header
- Documentation style
- Section ordering
- Comment conventions
- Token organization
- Maintenance notes

---

# Rules

The template must never contain implementation-specific values.

Its purpose is to provide structure only.

Replace every placeholder with values appropriate for the component being created.

---

# Benefits

Using a single template guarantees:

- consistent documentation
- predictable architecture
- easier code reviews
- lower maintenance cost
- uniform component quality

---

# Maintenance Notes

Update the Golden Template only when the Design System architecture changes.

Changes to this template affect all future components.
