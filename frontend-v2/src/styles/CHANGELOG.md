# Versioning Policy

## Major

Breaking architectural changes.

Examples:

- Folder restructuring
- Token renaming
- Removing components

---

## Minor

Backward-compatible improvements.

Examples:

- New components
- New tokens
- New documentation

---

## Patch

Bug fixes.

Examples:

- Documentation corrections
- Token fixes
- Typo corrections
