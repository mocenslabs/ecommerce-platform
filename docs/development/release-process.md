# Release Process

## Branch Strategy

main

Stable production code.

develop

Active development.

feature/*

Feature branches.

hotfix/*

Production fixes.

---

## Release Steps

1. Run tests.
2. Update documentation.
3. Update CHANGELOG.
4. Create Git tag.
5. Publish GitHub Release.
6. Deploy.

---

## Versioning

Semantic Versioning

MAJOR.MINOR.PATCH

Example:

1.0.0
