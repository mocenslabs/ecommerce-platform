# Notifications API Reference

## Overview

The Notifications application manages user notifications generated by business events.

---

# Responsibilities

- Order notifications
- Payment notifications
- System notifications
- Email triggers

---

# Base URL

/api/v1/notifications/

---

# Relationships

Receives events from:

- Orders
- Payments
- Inventory

---

# Frontend Integration Notes

Suggested features:

- Notification bell
- Unread counter
- Read status
- Real-time updates (future)
